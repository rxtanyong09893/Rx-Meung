# ระบบจัดการด้านยาปฐมภูมิ เครือข่าย รพ.สต. อำเภอเมืองปัตตานี

ย้ายจาก Google Apps Script + Google Sheet มาเป็น **GitHub Pages (หน้าเว็บ) + Supabase (ฐานข้อมูล)**
หน้าตาและการใช้งานเหมือนระบบเดิมทุกเมนู

## ทำงานเหมือนเดิม
- ล็อกอินด้วย **ชื่อผู้ใช้ + รหัสผ่าน 4 ตัว**, สมัครใช้งานแล้วรอแอดมินอนุมัติ, ใส่รหัสผิด 5 ครั้งล็อก 15 นาที, ไม่ใช้งาน 30 นาทีออกจากระบบอัตโนมัติ
- หน่วยบริการ: ขอเบิกยา · ประวัติคำขอ · ใบเบิกยา · ยืม-คืนยา · บันทึก ME
- แอดมิน: อนุมัติตัด LOT แบบ FEFO และออกเลขที่ใบเบิก ปีงบ/ลำดับ · ยกเลิกใบเบิก/รับยาคืน · คลังยา (คงเหลือ/LOT, รับยาเข้า, ทะเบียนยา, ปรับปรุง) · Stock Card · รายงาน 4 แบบ · ผู้ใช้งาน · บันทึกระบบ
- ใบเบิก/รายงาน: พิมพ์ A4 (TH SarabunPSK 16, แนวตั้ง/แนวนอนอัตโนมัติ), ดาวน์โหลด PDF, Word, CSV
- แจ้งเตือนแอดมินทาง LINE เมื่อมีคำขอเบิกใหม่ และ ME ระดับ E-I (ตั้งค่าได้ ไม่บังคับ)

## สิ่งที่เปลี่ยนจากระบบเดิม
| ระบบเดิม (GAS) | ระบบใหม่ |
|---|---|
| Google Sheet | ฐานข้อมูล Supabase (PostgreSQL) — อนุมัติเบิกเป็นขั้นตอนเดียวจบ จึงไม่มีคำขอค้าง "กำลังดำเนินการ" อีก |
| Word/PDF สร้างผ่าน Google Docs | สร้างในเบราว์เซอร์ · Word เป็นไฟล์ `.doc` เปิดได้ใน Microsoft Word |
| แชร์ LINE แบบลิงก์ไฟล์ใน Drive | แชร์ไฟล์ PDF ผ่านเมนูแชร์ของมือถือ หรือส่งข้อความแจ้งเลขที่เอกสาร |
| Trigger สำรองข้อมูลรายสัปดาห์ | ปุ่ม **ดาวน์โหลดสำรองข้อมูล (Excel)** ในเมนูบันทึกระบบ |
| รัน `setup()` / `resetAdminPassword()` | รันคำสั่ง SQL `select rx.reset_admin_password();` |

## ไฟล์
```
index.html, config.js, logo.jpg, js/      หน้าเว็บ (อัปโหลดขึ้น GitHub)
supabase/supabase-install.sql              ติดตั้งฐานข้อมูล (คำสั่งเดียว)
```

## ติดตั้ง

### 1. ฐานข้อมูล Supabase
1. เปิดโปรเจกต์ Supabase → **SQL Editor** → **New query**
2. เปิดไฟล์ `supabase/supabase-install.sql` → คัดลอกทั้งหมด → วาง → **Run**
   - ถ้ามีหน้าต่างเตือน *destructive operation* ให้กดยืนยัน (เป็นการลบตารางของเวอร์ชันทดลองก่อนหน้า ซึ่งไม่มีข้อมูลใช้งาน)
   - ขึ้น *Success. No rows returned* = สำเร็จ
3. **New query** → รันคำสั่งนี้ เพื่อสร้างบัญชีแอดมิน
   ```sql
   select rx.reset_admin_password();
   ```
   จดชื่อผู้ใช้และรหัสผ่านที่แสดง (ระบบบังคับเปลี่ยนรหัสเมื่อเข้าสู่ระบบครั้งแรก) — ลืมรหัสแอดมินก็รันคำสั่งเดิมนี้อีกครั้ง

### 2. หน้าเว็บ GitHub Pages
1. แก้ `config.js` ใส่ **Project URL** และ **anon / publishable key** ของ Supabase (ห้ามใช้ service_role / secret key)
2. อัปโหลดทุกไฟล์ขึ้น repository → **Settings → Pages** → Branch `main` / `(root)` → Save
3. เปิดลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` → เข้าสู่ระบบด้วยบัญชี admin

### 3. เริ่มใช้งาน
1. แอดมิน: **คลังยา → ทะเบียนยา** เพิ่มรายการยา → **รับยาเข้า** บันทึกยอดคงคลังตั้งต้นทีละ LOT
2. ส่งลิงก์ให้เจ้าหน้าที่ 10 หน่วยกด **สมัครใช้งาน** → แอดมินเมนู **ผู้ใช้งาน** → แก้ไข → สถานะ "ใช้งาน"

## ตั้งค่าเพิ่มเติม (SQL Editor)
```sql
-- ชื่อผู้รับผิดชอบคลังยา / ผู้อนุมัติ ที่แสดงบนใบเบิก
update rx.settings set value = 'ชื่อ-สกุล' where key = 'KEEPER';
update rx.settings set value = 'ตำแหน่ง' where key = 'KEEPER_TITLE';

-- แจ้งเตือน LINE (Messaging API): Channel access token และ userId/groupId ของแอดมิน
update rx.settings set value = 'TOKEN' where key = 'LINE_TOKEN';
update rx.settings set value = 'Uxxxxxxxx' where key = 'LINE_TO';
update rx.settings set value = 'https://<ชื่อผู้ใช้>.github.io/<repo>/' where key = 'APP_URL';
```
แต่ละบรรทัดรันทีละคำสั่ง (SQL Editor บางแบบรับได้ครั้งละ 1 คำสั่ง)

## ความปลอดภัย
- ข้อมูลทั้งหมดอยู่ใน schema `rx` ที่ไม่เปิดผ่าน API หน้าเว็บเข้าถึงได้ทางฟังก์ชัน `api()` เท่านั้น ซึ่งตรวจรหัสผ่านและสิทธิ์ทุกครั้ง
- หน่วยบริการเห็นเฉพาะข้อมูลของหน่วยตนเอง (คำขอ ใบเบิก ยืม-คืน ME) แอดมินเห็นทั้งหมด
- รหัสผ่านเก็บแบบเข้ารหัส bcrypt ไม่มีใครเห็นรหัสจริง
- ไฟล์สำรองข้อมูลมี HN ผู้ป่วย เก็บในเครื่องหรือไดรฟ์ส่วนตัว ห้ามแชร์
