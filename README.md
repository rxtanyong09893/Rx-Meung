# ระบบคลังยา เครือข่าย รพ.สต. (10 แห่ง)

เว็บแอปบริหารคลังยา รพ.สต. — หน้าเว็บโฮสต์บน **GitHub Pages** ฐานข้อมูลและระบบล็อกอินบน **Supabase**

## ความสามารถ (รอบที่ 1: คลังยา)
- **ภาพรวม** — admin เห็นสรุปทั้ง 10 แห่ง (มูลค่าคงคลัง, ต่ำกว่าจุดสั่งซื้อ, ใกล้หมดอายุ, หมดอายุค้างคลัง); แต่ละแห่งเห็นล็อตใกล้หมดอายุ ≤90 วัน และรายการที่ควรเบิกพร้อมจำนวนแนะนำ
- **คงคลัง** — คงเหลือ, ใช้เฉลี่ย/เดือน (ย้อนหลัง 3 เดือน), พอใช้กี่เดือน, ล็อต/วันหมดอายุ, ตั้งจุดสั่งซื้อ min/max ราย รพ.สต.
- **รับยา** — บันทึกหลายรายการต่อใบเบิก (Lot, วันหมดอายุ, ทุน)
- **จ่ายยา** — ตัดล็อตแบบ FEFO อัตโนมัติ และไม่จ่ายล็อตที่หมดอายุแล้ว
- **ตัดหมดอายุ / ตรวจนับ** — ตัดยาหมดอายุ/เสื่อม, ปรับยอดตามการตรวจนับ (บังคับใส่เหตุผล)
- **ประวัติ** และ **รายงานรับ-จ่ายรายเดือน** (ยกมา-รับ-จ่าย-ปรับ-คงเหลือ-มูลค่า) ส่งออก CSV / พิมพ์ได้
- **ผู้ดูแลระบบ** — กำหนดผู้ใช้ให้ รพ.สต., บัญชียา, แก้ชื่อหน่วยบริการ, นำเข้าข้อมูลจาก CSV

### โมดูลวัสดุ / ทะเบียนคุมวัสดุ
- ปุ่ม **ยา | วัสดุ** มุมขวาบนสลับทุกเมนูให้ทำงานกับยาหรือวัสดุ (วัสดุการแพทย์ วิทยาศาสตร์ สำนักงาน งานบ้านงานครัว ฯลฯ)
- วัสดุไม่บังคับ Lot / วันหมดอายุ (วัสดุที่มีวันหมดอายุ เช่น น้ำยา แถบตรวจน้ำตาล ใส่ได้ และจะขึ้นเตือนใกล้หมดอายุเหมือนยา)
- รับวัสดุแต่ละครั้งแยกเป็นรอบรับของตัวเอง → จ่ายออกแบบ **FIFO** และมูลค่าคงเหลือคิดตามราคาที่ซื้อจริง
- เมนู **ทะเบียนคุม** — บัญชีวัสดุ/บัญชียา รายปีงบประมาณ (ต.ค.–ก.ย.) รูปแบบ: วันที่, ที่เอกสาร, รับจาก/จ่ายให้, ราคาต่อหน่วย, รับ, จ่าย, คงเหลือ, มูลค่าคงเหลือ พร้อมจำนวนอย่างสูง/อย่างต่ำ — เลือกรายการเดียว หรือเว้นว่างเพื่อพิมพ์ทุกรายการ (ขึ้นหน้าใหม่ทีละรายการ)

**ความปลอดภัย:** Row Level Security — เจ้าหน้าที่เห็น/บันทึกได้เฉพาะ รพ.สต. ของตน, admin เห็นทั้งหมด; การเคลื่อนไหวคลังบันทึกผ่านฟังก์ชันฝั่งฐานข้อมูลเท่านั้น (แก้ยอดตรง ๆ หรือลบประวัติไม่ได้)

## โครงสร้างไฟล์
```
index.html, styles.css, app.js     หน้าเว็บ
config.js                          ค่าเชื่อมต่อ Supabase  ← ต้องแก้
supabase/migrations/..._init.sql   โครงสร้างฐานข้อมูล
templates/*.csv                    แม่แบบย้ายข้อมูลจาก Google Sheet
```

## ขั้นตอนติดตั้ง

### 1. Supabase
1. สร้างโปรเจกต์ที่ https://supabase.com (เลือก Region: Southeast Asia (Singapore))
2. เมนู **SQL Editor** → รันไฟล์ใน `supabase/migrations/` **ตามลำดับชื่อไฟล์**: `20261106000000_init.sql` แล้วตามด้วย `20261106100000_supplies.sql` (ถ้าเคยรันไฟล์แรกไปแล้ว รันเฉพาะไฟล์ที่สอง ข้อมูลเดิมไม่หาย)
3. **Authentication → Providers → Email**: เปิดใช้ ถ้าไม่ต้องการให้ผู้ใช้ยืนยันอีเมล ให้ปิด *Confirm email*
4. **Project Settings → API**: คัดลอก *Project URL* และ *anon public key*

> รหัสผ่านขั้นต่ำของ Supabase คือ 6 ตัวอักษร (ระบบเดิมใช้ 4 ตัว ผู้ใช้ต้องตั้งใหม่)

### 2. GitHub
1. สร้าง repository ใหม่ (เช่น `pcu-drug-stock`) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. แก้ `config.js` ใส่ URL และ anon key จากข้อ 1.4 (**ห้ามใส่ service_role key**)
3. **Settings → Pages** → Source: *Deploy from a branch* → `main` / `(root)` → Save
4. ได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/pcu-drug-stock/`
5. กลับไป Supabase → **Authentication → URL Configuration** ใส่ลิงก์นี้ใน *Site URL*

(ทางเลือก) เชื่อม Supabase กับ GitHub ผ่าน **Project Settings → Integrations → GitHub** เพื่อให้ไฟล์ใน `supabase/migrations` ถูกรันอัตโนมัติเมื่อ push

### 3. ตั้งผู้ดูแลระบบคนแรก
1. เปิดเว็บ → สมัครใช้งานด้วยอีเมลของเภสัชกร
2. Supabase **SQL Editor** รัน:
   ```sql
   update public.profiles set role = 'admin' where email = 'อีเมลของคุณ';
   ```
3. เข้าสู่ระบบใหม่ → เมนู **ผู้ดูแลระบบ**

### 4. ตั้งค่าเริ่มต้น และย้ายข้อมูลจาก Google Sheet
1. แก้ชื่อ/รหัสหน่วยบริการ 10 แห่งให้ถูกต้อง (ระบบใส่ชื่อชั่วคราวไว้)
2. Export Sheet บัญชียาและวัสดุ เป็น CSV ตามหัวคอลัมน์ `templates/drugs_template.csv` → นำเข้า (คอลัมน์ `item_type` ใส่ `drug` หรือ `supply`; ว่าง = ยา)
   - ทะเบียนคุมวัสดุเดิม: ใส่ยอดคงเหลือ ณ วันเริ่มใช้ระบบเป็นยอดยกมา (วัสดุเว้น lot_no / exp_date ได้)
3. Export ยอดคงคลังแต่ละล็อตของทุกแห่ง เป็น CSV ตาม `templates/opening_balance_template.csv` → นำเข้า (ใช้ `hcode` จับคู่ รพ.สต., `drug_code` จับคู่ยา; วันที่ใช้ได้ทั้ง ค.ศ. และ พ.ศ.)
   - นำเข้าซ้ำ ยอดจะถูก **บวกเพิ่ม** — นำเข้าครั้งเดียว
4. ให้เจ้าหน้าที่แต่ละแห่งสมัครใช้งาน → admin กำหนด รพ.สต. ให้ในตาราง "ผู้ใช้งาน"
5. ตั้งจุดสั่งซื้อ (min/max) ที่หน้า **คงคลัง** → คลิกรายการยา

## หมายเหตุ
- ฟรีแพ็กเกจ Supabase จะหยุดโปรเจกต์ชั่วคราวถ้าไม่มีการใช้งาน 7 วัน (เข้าใช้ปกติทุกวันไม่มีปัญหา) และควรสำรองข้อมูลเป็นระยะ (Database → Backups หรือ export CSV)
- มูลค่าคงคลังคำนวณจาก "ราคา/หน่วย" ในบัญชียา
